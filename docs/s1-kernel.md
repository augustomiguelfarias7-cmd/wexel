# S1 kernel architecture

S1 is the Wexel-owned C++ core compiled into a WebAssembly module. The module
uses a freestanding ABI instead of WASI so the Wexel runtime explicitly owns
the host capabilities it grants. It has no shell; BusyBox remains a separate
component managed by Wexel.

The first implementation contains:
- one-time kernel initialization and the literal version `S version S1.0.0.0`;
- a bounded service registry with register/start/stop/state operations;
- a bounded event ring for lifecycle diagnostics;
- virtual proc entries for version, uptime ticks, service state, memory-layout
  constants, and recent events;
- a socket ABI gated by an explicit capability bit and delegated to host
  imports, so S1 cannot silently bypass Wexel's network policy.

This is a real freestanding WASM module with state and callable kernel APIs,
not a Linux kernel and not a general-purpose OS by itself. In particular,
network calls require host implementations of the imported `wexel.socket_*`
functions. The build script intentionally uses Clang/LLD directly and does not
use Emscripten or GitHub Actions.

Build locally with `bash scripts/build-s1-kernel.sh`. The generated binary is
an artifact and is not generated by source-control operations.
